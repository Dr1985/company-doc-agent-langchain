# 元流科技有限公司 — IT 与信息安全规范

> **版本**: v2.3  
> **生效日期**: 2025-11-01  
> **适用人员**: 全体员工（含外包、实习生）  
> **制定部门**: IT 运维部 & 信息安全委员会  
> **合规依据**: ISO 27001、《网络安全法》《数据安全法》《个人信息保护法》

---

## 一、总则

### 1.1 目的

为保护公司信息资产（数据、代码、文档、客户信息等）的机密性、完整性和可用性，防范信息泄露、篡改和丢失风险，确保公司业务连续性和合规性，特制定本规范。

### 1.2 适用范围

本规范适用于元流科技所有员工、外包人员、实习生及以任何方式接入公司信息系统的第三方人员。

### 1.3 信息安全等级

| 等级 | 定义 | 示例 |
|------|------|------|
| **绝密** | 泄露将造成公司重大损失 | 产品核心算法、未公开财务数据、并购计划 |
| **机密** | 泄露将造成公司较大损失 | 客户合同、员工薪酬数据、技术方案 |
| **内部** | 仅限公司内部知悉 | 内部制度文档、会议纪要、一般项目文档 |
| **公开** | 可对外发布 | 公司官网内容、产品白皮书、招聘信息 |

## 二、账号与密码管理

### 2.1 账号申请与注销

- 新员工入职后由 IT 部门统一创建各系统账号（邮箱、OA、代码仓库、企业微信、VPN 等）。
- 离职员工账号在最后工作日当日 18:00 统一禁用，30 天后自动删除。
- 账号权限遵循**最小权限原则**（Least Privilege），仅授予完成本职工作所必需的权限。
- 转岗员工的原岗位权限须在转岗后 5 个工作日内回收。

### 2.2 密码策略

| 项目 | 要求 |
|------|------|
| 最小长度 | 12 位 |
| 复杂度 | 必须包含大写字母、小写字母、数字、特殊字符中的至少 3 类 |
| 更换周期 | 每 90 天强制更换 |
| 历史记忆 | 不得与最近 10 次密码重复 |
| 共享禁止 | 严禁共享个人账号密码 |

### 2.3 密码管理器

- 公司统一使用 **1Password Business** 管理密码。
- 所有业务系统密码必须在 1Password 中存储，严禁在浏览器"记住密码"功能中保存。
- 1Password 主密码须单独记忆，不得存储在任何电子设备中。
- 离职前须将个人 1Password 保险库中所有业务相关条目转移至部门共享保险库。

### 2.4 多因素认证（MFA）

- 以下系统强制启用 MFA：企业邮箱、OA 系统、代码仓库（GitLab/GitHub Enterprise）、云服务控制台（AWS/阿里云）。
- MFA 推荐使用 1Password 内置 OTP 或硬件安全密钥（YubiKey）。
- 禁止将 MFA 验证码发送给任何人（包括自称 IT 部门的人员）。

## 三、设备与网络安全

### 3.1 办公设备

- 公司统一配备笔记本电脑（ThinkPad X1 / MacBook Pro），入职满 3 年的可申请更换。
- 办公设备必须安装公司指定的终端安全软件（CrowdStrike Falcon），禁止自行卸载或禁用。
- 离开工位时必须锁屏（Windows：`Win+L`，Mac：`Control+Command+Q`）。
- 禁止使用个人设备连接公司内部网络。如因特殊情况需要使用个人设备，须提前向 IT 部申请，完成终端安全检查后方可接入访客网络。

### 3.2 网络接入

- 办公网分为**内网**（有线 + WiFi-Internal）和**访客网**（WiFi-Guest），两者物理隔离。
- 内网仅允许公司设备接入，使用 WPA3-Enterprise + 802.1X 证书认证。
- 访客网有效期 24 小时，每天由前台统一提供一次性验证码。

### 3.3 VPN 远程接入

- 远程办公须通过 **WireGuard VPN** 接入公司内网。
- VPN 配置文件由 IT 部统一签发，每人独享一机一密钥。
- VPN 连接后禁止使用 P2P 下载、在线游戏等占用大量带宽的非工作应用。
- IT 部监控异常 VPN 流量（如大量数据上传），发现异常立即断开并通知当事人。

### 3.4 无线网络安全

- 禁止私自搭建无线热点（含手机热点）接入公司内部系统。
- 出差时使用公共 WiFi 必须同时启用 VPN，否则禁止访问任何公司内部系统。
- 禁止将公司设备连接到来历不明的 USB 充电桩（存在 BadUSB 攻击风险），建议使用自带充电头。

## 四、数据安全

### 4.1 数据分类与标记

所有电子文档须在文件头标注密级：

```
文档密级: 内部
创建日期: 2026-01-15
创建人: 张三
```

### 4.2 存储与传输

- **内部及以下**文档：可存储在公司 Google Workspace / 企业微信微盘。
- **机密**文档：仅存储在受控的 Google Drive 共享盘（Access Controlled Shared Drive），默认仅部门内可访问。
- **绝密**文档：仅存储在加密的本地文件服务器（非云端），访问需双人授权。
- 含敏感信息的文件传输须使用公司加密通道（1Password Send 或 WireGuard VPN + SFTP），严禁通过个人微信、QQ、个人邮箱传输。
- 代码仓库（GitLab）中的敏感信息（API 密钥、数据库密码、证书等）必须使用 `.gitignore` 排除或使用 GitLab CI/CD Variables 管理。代码中硬编码密钥属于严重违规。

### 4.3 数据备份

| 系统 | 备份频率 | 保留周期 |
|------|---------|---------|
| 数据库（PostgreSQL） | 每日全量 + 实时 WAL 归档 | 30 天 |
| Google Workspace | 自动云端备份 | 90 天 |
| GitLab 代码仓库 | 每日镜像到异地 | 永久 |
| 文件服务器 | 每日增量，每周全量 | 90 天 |

- 个人笔记本电脑中的重要工作文件须同步至 Google Drive / OneDrive，避免本地硬盘故障导致数据丢失。IT 部不负责恢复未同步的本地数据。

### 4.4 数据销毁

- 纸质文件：机密及以上等级须使用碎纸机粉碎（横切式）。
- 电子文件：删除后须清空废纸篓/回收站；SSD 硬盘退役前使用 ATA Secure Erase 安全擦除。
- 离职员工的云端数据，IT 部在账号禁用后 30 天内归档至部门共享盘，原数据从个人空间彻底清除。

## 五、软件使用规范

### 5.1 允许安装的软件

员工可自行安装以下类别软件：

- 开发工具：VS Code、JetBrains 系列（由公司统一购买 License）、Docker、Git
- 办公工具：企业微信、飞书、腾讯会议、Notion
- 浏览器：Chrome、Edge、Firefox（须安装公司指定的安全扩展）

### 5.2 禁止安装或使用的软件

- 盗版软件、未经授权的破解版软件
- P2P 文件共享软件（BitTorrent、迅雷等）
- 加密货币挖矿软件
- 任何形式的网络代理/翻墙工具（公司 VPN 除外）
- 境外 AI 服务（ChatGPT、Claude 等）的网页版如需使用须走公司审批通道，通过公司统一采购的 API 接入

### 5.3 软件采购

- 工作所需的付费软件由 IT 部统一采购和分配 License。
- 不得以个人名义购买后用公司报销（License 归属问题）。

## 六、邮件与通讯安全

### 6.1 钓鱼邮件防范

- 对索要密码、验证码、紧急转账的邮件保持高度警惕。
- 收到可疑邮件请通过"Report Phishing"按钮举报，不要点击任何链接或下载附件。
- IT 部定期进行钓鱼邮件演练，识别失败者须参加额外安全培训。

### 6.2 邮件加密

- 发送含机密信息的邮件，须使用 Gmail 的"机密模式"或 S/MIME 加密。
- 发送给客户的含合同/报价的邮件，建议设置查看密码和过期时间（7 天）。

## 七、安全事件响应

### 7.1 安全事件定义

以下情形属于安全事件，必须立即上报：

- 设备丢失/被盗
- 账号异常登录（异地、非工作时间）
- 发现病毒/勒索软件
- 数据意外泄露或丢失
- 收到外部安全威胁（如勒索邮件）

### 7.2 报告流程

1. 发现安全事件后 **15 分钟内**通知 IT 运维部（邮箱：security@yuanliu-tech.com，电话：0755-8888-9999 转 3）。
2. IT 运维部在 **30 分钟内**启动应急响应。
3. 涉及数据泄露的，在 **24 小时内**完成初步影响评估。
4. 重大安全事件按《数据安全法》规定在 **72 小时内**向主管部门报告。

### 7.3 违规处罚

| 违规行为 | 处罚 |
|---------|------|
| 密码共享、未锁屏 | 口头警告 |
| 通过个人渠道传输内部文档 | 书面警告 |
| 未经授权访问他人数据 | 记过处分 |
| 故意泄露机密/绝密信息 | 解除劳动合同，追究法律责任 |
| 在代码中硬编码密钥并推送到公开仓库 | 记过处分；如造成实际损失，解除劳动合同 |

## 八、合规与审计

- IT 部每季度进行一次安全审计，包括账号权限审查、终端合规检查、VPN 日志分析。
- 每年组织一次全员信息安全培训和考试，考试不合格者须补考。
- 公司每年进行 ISO 27001 监督审核，各部门须配合提供审核材料。
- 所有第三方服务商须签署《数据处理协议》（DPA），确保数据处理符合《个人信息保护法》要求。
