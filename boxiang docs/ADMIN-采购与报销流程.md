# 元流科技有限公司 — 采购与报销流程

> **版本**: v2.0  
> **生效日期**: 2026-02-01  
> **适用人员**: 全体员工  
> **制定部门**: 财务部 & 行政部

---

## 一、总则

### 1.1 目的

为规范公司采购行为和费用报销流程，控制成本，防范财务风险，确保公司资金使用的合规性和透明度，特制定本流程。

### 1.2 适用范围

本流程适用于元流科技全部采购行为（含固定资产采购、日常消耗品采购、服务采购）和全部费用报销。

---

## 二、采购管理

### 2.1 采购分类

| 类别 | 金额范围 | 说明 |
|------|---------|------|
| 小额采购 | ≤ 2000 元 | 日常办公用品、耗材、书籍 |
| 一般采购 | 2000–50000 元 | 设备、软件 License、培训 |
| 大额采购 | 50000–200000 元 | 服务器、外包服务 |
| 重大采购 | > 200000 元 | 需招标或三方比价 |

### 2.2 审批权限

| 金额 | 审批人 |
|------|--------|
| ≤ 2000 元 | 直属上级 |
| 2000–10000 元 | 直属上级 + 部门负责人 |
| 10000–50000 元 | 部门负责人 + 财务总监 |
| 50000–200000 元 | 部门负责人 + 财务总监 + CEO |
| > 200000 元 | 董事会审批 |

### 2.3 采购流程

**标准采购流程（> 2000 元）**：

1. **需求提交**：申请人在 OA 提交《采购申请单》，写明采购物品、数量、预算、用途、期望到货日期。
2. **供应商选择**：
   - 50000 元以下：可直接选择已有合格供应商。
   - 50000 元以上：须至少取得 **3 家**供应商的报价，OA 中上传比价单。
3. **审批**：按金额逐级审批。
4. **下单**：审批通过后由行政部统一采购（或授权申请人在指定平台下单）。
5. **验收**：物品到货后，申请人验收并在 OA 确认收货，上传验收报告或照片。
6. **付款**：财务部在收到发票和验收确认后，按合同约定的付款条件执行付款。

**紧急采购**：因紧急情况无法走正常审批的，可先口头报备部门负责人，事后 3 个工作日内补办 OA 审批。事后未补办的由个人承担费用。

### 2.4 固定资产管理

- 单价超过 2000 元的采购视为固定资产，行政部登记入固资台账，粘贴资产标签（含资产编号和二维码）。
- 固定资产编号规则：`YUANLIU-{资产类别}-{年份}-{4位序号}`。例如：`YUANLIU-IT-2026-0038`。
- 资产每年年末盘点一次，盘亏须查明原因并追责。
- 员工离职须归还全部公司资产，资产遗失按折旧后净值赔偿。

### 2.5 供应商管理

- 新供应商须经资质审核后纳入合格供应商名录。
- 主要供应商每年评估一次，评估维度：价格竞争力、交付时效、售后服务、合规性。
- 连续两次评估不合格的供应商从名录中移除。

## 三、费用报销

### 3.1 可报销费用类别

| 类别 | 包含项目 | 说明 |
|------|---------|------|
| 差旅费 | 机票、火车票、酒店、餐补、市交 | 详见《HR-出差管理细则》 |
| 招待费 | 客户餐饮、商务活动 | 人均 ≤ 200 元，不得含高档烟酒 |
| 培训费 | 课程、会议、考试 | 提前申请，与岗位相关 |
| 办公费 | 文具、耗材、图书 | ≤ 100 元/月/人 |
| 通讯费 | 手机话费 | ≤ 100 元/月（仅限销售岗和对外岗） |
| 加班餐 | 加班时晚餐 | ≤ 50 元/次，需系统有加班记录 |
| 交通费 | 因公打车、地铁 | 市内实报实销 |

### 3.2 报销标准

| 项目 | 标准 | 凭据 |
|------|------|------|
| 加班晚餐 | ≤ 50 元/次 | 发票 + 加班记录 |
| 因公打车 | 实报实销 | 电子发票 |
| 手机话费 | ≤ 100 元/月 | 发票 |
| 购书 | ≤ 100 元/月 | 发票 + 书名 |

### 3.3 发票规范

所有报销须开具**增值税专用发票**（小规模纳税人可开普通发票），发票须满足：

- 抬头：**元流科技有限公司**
- 税号：91440300MA5K8XXXXX
- 发票内容与实际消费一致，不得用无关发票顶替
- 电子发票须上传 PDF/OFD 原件至 OA
- 发票金额超过 500 元的须附支付凭证（银行流水或支付宝/微信账单截图）

### 3.4 报销时限

- 费用发生后 **30 天**内完成报销申请，逾期原则上不予报销。
- 每月 25 日为当月报销截止日，25 日之后提交的计入下月处理。
- 跨年度费用须在次年 1 月 10 日前提交完毕。

### 3.5 报销流程

1. 申请人在 OA 提交《费用报销单》，附上发票、支付凭证及必要的说明（如招待对象、交通事由等）。
2. 直属上级审批（1 个工作日内）。
3. 财务部审核票据合规性和预算匹配（2 个工作日内）。
4. 审核通过后，款项在下一个**每周三**批量支付（如周三是节假日则顺延至下一个工作日）。
5. 审核不通过则退回申请人补充材料或修改。

### 3.6 禁止行为

- 虚假报销（虚构费用、虚增金额）：一经查实，追回报销款，记书面警告，情节严重者解除劳动合同。
- 拆分报销（将大额费用拆成多笔小额以规避审批）：一旦发现，退回全部相关报销。
- 重复报销：一经发现，追回多报款项并通报批评。
- 将个人消费（如家庭聚餐、个人旅行）混入公司报销：记过处分。

## 四、预付款与备用金

### 4.1 预付款申请

- 部分供应商要求预付（如 SaaS 年费、展会定金），可在 OA 提交《预付款申请单》。
- 预付款比例一般不超过合同总金额的 50%。
- 预付款完成后，申请人须在合同约定的交付期后 10 个工作日内完成验收和尾款支付。

### 4.2 部门备用金

- 行政部、市场部各保留 2000 元备用金，用于日常零星采购（≤ 200 元/次）。
- 备用金由部门负责人指定保管人，每季度清点一次，年底归还后重新借款。
- 备用金支出须登记台账，凭票核销，不得坐支。

---

## 五、预算管理

### 5.1 部门预算

- 各部门每年 12 月编制下年度预算（含差旅、招待、培训、采购等），财务部汇总后报 CEO 审批。
- 每季度进行预算执行分析，超预算 10% 以上须提交预算调整申请。

### 5.2 预算外支出

- 预算外支出须填写《预算外支出申请单》，由部门负责人 + 财务总监 + CEO 三方审批。
- 预算外支出审批通过后从公司总预备金中列支。
